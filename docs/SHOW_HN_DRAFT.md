# Show HN: TripSync AI, a shared trip planner for groups

I built TripSync AI for groups that want to work on one itinerary together. Everyone in a trip room can see updates as the plan takes shape. The room also supports budget splits and voting on activities.

[Try the hosted demo](https://tripsync-ai-real-time-collaborative.onrender.com/). Create a trip in one browser profile, join it with a second account in another profile, and add a place to the itinerary. Watch it appear in the second session. The sample destinations and prices are fictional.

I’d like to hear where the invite, shared editing, and voting flows could be clearer.
